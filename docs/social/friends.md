# 👥 Friends & Social System

Stay connected with your friends and teammates using our built-in social system. Build your list and see who is online.

---

## 📜 Friend Commands

All friendship features can be accessed using the `/friend` or `/f` prefix:

| Command | Alternative | Description |
| :--- | :--- | :--- |
| `/friend` | `/f` | Opens your Friends list GUI dashboard. |
| `/f add <player>` | - | Sends a friend request to an online player. |
| `/f remove <player>` | - | Removes a player from your friends list. |
| `/f list` | - | Displays a list of your friends and their online status in chat. |
